# 🔐 Password Security Awareness App

## 📌 Problem Statement

Create an application that teaches users about password security and evaluates their password practices **without storing their actual passwords**.

## 💡 About the Project

The **Password Security Awareness App** is a web application designed to help users understand how to create and maintain strong passwords.

The application evaluates password practices and provides useful security suggestions. For privacy and security, the application **does not store users' actual passwords**.

Our main goal is to make password security easy to understand and help users develop better password habits.

## 🎯 Objectives

- Teach users about password security.
- Help users understand what makes a password strong.
- Evaluate password strength and security practices.
- Provide security tips and suggestions.
- Protect user privacy by not storing actual passwords.
- Provide a simple and user-friendly interface.

## ✨ Features

- 🔑 Password strength evaluation
- 📊 Security score and feedback
- 💡 Password security tips
- 🛡️ Best practices for creating strong passwords
- 🔒 No storage of actual passwords
- 📱 Simple and responsive user interface
- ☁️ Supabase database for storing non-sensitive application data

## 🛠️ Technologies Used

- **HTML** – Structure of the web pages
- **Tailwind CSS** – Styling and responsive design
- **Supabase** – Database and backend services
- **Git** – Version control
- **GitHub** – Source code management
- **Replit** – Development and testing
- **Vercel** – Deployment and hosting

## 🏗️ How It Works

1. The user enters a password for evaluation.
2. The application checks different password security factors.
3. The password is evaluated locally without storing the actual password.
4. A security score and feedback are shown to the user.
5. The application provides suggestions to improve password security.
6. Only non-sensitive information required by the application is stored in the database.

## 🔐 Privacy & Security

Privacy is one of the main focuses of this project.

**Actual passwords are never stored in the database.**

The application only uses the password temporarily for evaluation and provides feedback to the user. This reduces the risk of exposing sensitive password information.
